## 배포 주소 조합

1. `PUBLICATION_MODE=public`, `BASE_PATH=/qit-lab/`, `SITE_URL=https://example.org`: 빌드·검증 통과, CNAME 없음.
2. `PUBLICATION_MODE=public`, `BASE_PATH=/`, `SITE_URL=https://example.org`, `CUSTOM_DOMAIN=example.org`: 빌드·검증 통과, CNAME 생성.
3. 최종 결과물을 기본 review 모드·루트 경로로 다시 생성: 빌드·검증 통과, CNAME 없음·noindex·검토 명단 표시.

`example.org`는 로컬 검사에만 사용한 예약 예시 도메인입니다. 실제 등록·연결·배포하지 않았으며 최종 검토 결과물에는 해당 주소가 설정되어 있지 않습니다. 잘못된 공개 URL, HTTP URL, 사용자 도메인과 base path 충돌 등 8개 구성 조합도 확인했습니다.
