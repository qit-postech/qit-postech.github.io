# QIT 연구실 홈페이지 개편 검토서

기준일: 2026-10-13 · 대상: POSTECH 물리학과 Quantum Information Theory Group

이 결과물은 KIST 시절 사이트를 근거별로 분리해 정리한 **한·영 연구실 홈페이지 검토본**입니다. 현재 GitHub 조직·저장소는 `qit-postech/qit-postech.github.io`로 확정되었고 사용자 승인으로 공개 전환했습니다. `https://qit-postech.github.io` 배포를 준비 중이며 게시 성공은 아직 확인하지 않았습니다. 학교 도메인 변경과 기존 사이트 수정은 수행하지 않았습니다. 아래 과거 조사 결과는 당시 근거 기록으로 유지하며, 사용자 확인과 기관 공식 검증을 구분합니다.

## 1. 조사 결과와 출처의 구분

기존 [QIT@KIST 사이트](https://sites.google.com/view/qitkist/)의 공개 메뉴 다섯 개를 조사했습니다. Home, Group members, Researches, Publications, Contact에 소개·인력·연구·서지·연락처가 분산되어 있습니다. 링크되지 않은 페이지나 비공개 페이지의 부재까지 확인한 것은 아닙니다.

출처 상태는 다음과 같이 구별합니다.

| 상태 | 의미 | 새 사이트에서의 처리 |
| --- | --- | --- |
| 기존 원문 | KIST 시절 사이트에 실제로 적힌 내용 | 과거 기록으로 보존하며 현재 소속·역할로 자동 승계하지 않음 |
| 공식 확인 | POSTECH 공식 학과·전공 페이지 또는 논문 출판사와 대조 | 확인한 범위 안에서 사용 |
| 사용자 확인 | 이번 대화에서 전달받은 현황 | 공식 확인과 구별하고 공개 범위까지 확정한 뒤 사용 |
| 확인 대기 | 현황·권리·일정 등의 근거가 부족함 | 미확정 정보는 정식 공개에서 제외 |

기존 [Publications](https://sites.google.com/view/qitkist/publications)에서 73개 표시 항목을 대조해 중복 19개를 제거하고 고유 서지 54개를 추출했습니다. 표시 연도는 2005–2024입니다. Recent에만 실린 2024년 논문도 있어 Full 목록만 옮기면 누락이 생깁니다. 2025–2026년 논문이 없다는 뜻도 아닙니다.

과거 54건에 새로 확인한 **출판 논문 5건(2026), 프리프린트 1건(2025), 해설·리뷰 1건(2024)**을 추가해 총 **61건**을 수록했습니다. 자세한 판본·동일인 검증은 [논문 갱신 기록](PUBLICATIONS-AUDIT.ko.md)을 참고하세요.

과거 54개 중 두 편은 출판사에서 추가 대조했습니다. [PRX Quantum 5, 030322](https://journals.aps.org/prxquantum/abstract/10.1103/PRXQuantum.5.030322)와 [Physical Review Letters 133, 050605](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.133.050605)입니다. 나머지 52개는 기존 사이트 전사 자료가 바탕입니다. 이 중 7개는 DOI·제목만 추가 대조했고, 전체 메타데이터를 전수 검증한 것으로 표시하지 않습니다. 출판 당시 KIST 소속을 현재 POSTECH 소속으로 바꾸지도 않습니다.

기존 다섯 페이지의 콘텐츠 이미지 요소는 23개이며, 별도로 반복 로고 요소가 있습니다. 공개 페이지에서 배치·유형·이미지 로드를 확인했지만 사진·연구 도해·표지·로고의 재사용 허락은 확인하지 못했습니다. 원본 사진을 새 사이트에 복제하지 않았습니다.

## 3. 구성원 현황: 총 14명

연구책임자 1명, 현재 학생 6명, 이전 구성원 7명을 기관과 근거별로 구분합니다. 학생·이전 구성원의 사진이나 개인 연락처는 포함하지 않습니다.

- POSTECH 박사과정 Kwang-Jun Choi(최광준), Woo-Won Seo(서우원), Jun-Hee Cho(조준희)의 영문 이름과 역할은 사용자 지정 PPT v49의 2쪽을 근거로 합니다. 한글 이름은 2026-10-13 사용자가 직접 확인했습니다.
- 신정현·임성엽·정세원은 사용자가 현재 KIST 학생으로 확인했습니다. POSTECH 학생으로 표시하거나 석·박사 단계를 임의로 정하지 않습니다.
- 이전 구성원은 사용자가 지정한 Sangjin Lee, Hyukgun Kwon(권혁건), Nuri Kang과 기존 Google 사이트 Alumni의 Hatice Mesakkat, Wooyeong Song, Jaehak Lee, Shrobona Bagchi입니다. 과거 역할과 현재 또는 당시 이동처는 별도 필드로 표시합니다.
- Sangjin Lee와 Shrobona Bagchi의 KIAS QUC Research Fellow, Hyukgun Kwon의 세종대학교 조교수, Nuri Kang의 Yale 응용물리학 박사과정은 공식 자료로 확인했습니다. Wooyeong Song의 KISTI 선임연구원과 Jaehak Lee의 KIST 선임연구원은 과거 사이트 기록으로만 표시합니다. Hatice Mesakkat의 현재 소속은 미확인입니다.

이전 구성원 7명은 공개 직업 정보의 추가를 명시한 사용자 요청에 따라 `approvedForPublic: true`로 반영했습니다. 현재 학생 6명도 이후 사용자의 공개·배포 요청에 따라 `approvedForPublic: true`로 전환하고 `publicationApproval`에 근거를 기록했습니다. 공개 모드에는 연구책임자·현재 학생 6명·이전 구성원 7명을 표시합니다. 학생 정보의 사용자 제공·확인 수준은 그대로이며 기관 공식 검증을 뜻하지 않습니다. 게시 성공은 아직 확인하지 않았습니다.

‘이전 구성원’은 졸업·학위 취득을 뜻하지 않습니다. 과거 KIST 표기만으로 현재 POSTECH의 Kwang-Jun Choi를 이전 구성원에 중복 등록하지 않았습니다. 이름·기간·소속별 출처와 확인 수준은 [구성원 근거](PEOPLE-EVIDENCE.ko.md)에 기록했습니다.

## 4. 확정된 연락처와 미확정 항목

[POSTECH 물리학과 교수 소개](https://ph.postech.ac.kr/physics/member/professor.do?articleNo=36802&mode=view)에 연구실명, 업무 이메일 `swleego@postech.ac.kr`, 전화 `054-279-2083`, 호실 `3-417`이 게시되어 있습니다. 청암로 77, 우편번호 37673은 학과 공통 우편주소입니다. 이를 연구실 전용 출입 위치로 설명하거나 `3-417`을 임의의 건물명으로 확장하지 않습니다.

공식 페이지의 ‘전임교수’만으로 Assistant Professor 또는 Full Professor를 확정하지 않습니다. 정확한 KIST → POSTECH 이전일, 학생실 위치, 인력의 추가 변동, 현재 채용, 협력 프로젝트 기간, 향후 추가할 사진의 게재 범위도 별도 확인 대상입니다. 공식 워드마크의 출처와 사용 조건은 [디자인 자산 안내](DESIGN-ASSETS.ko.md)에 분리해 기록했습니다.

학과 페이지는 이미 `qit.postech.ac.kr`을 연구실 홈페이지로 연결합니다. 2026-10-13 조회에서 A 레코드 `141.223.5.166`이 확인되었고 HTTP·HTTPS는 모두 404였습니다. 이는 도메인이 비어 있거나 사용자가 변경할 권한이 있다는 증거가 아닙니다. 기존 서비스 담당자와 사용권·전환 방식을 확인해야 합니다.

## 6. 디자인 방향

크림색 바탕과 짙은 자주색을 중심으로 세리프 제목, 넓은 여백, 읽기 편한 본문을 사용합니다. 헤더와 푸터에는 공식 POSTECH 워드마크를 원본 색과 비율로 적용합니다. 교수·학생 사진은 포함하지 않고 논문·연구·구성원을 중심으로 구성했습니다.

한·영 Home과 Research에는 Figma에서 새로 제작한 800 × 480 연구 도해 세 종을 사용합니다. 양자컴퓨팅은 H/CNOT 회로와 개념적 오류정정 격자, 양자통신은 노드·중계기·얽힘 연결과 점선 고전통신, 기초·센싱은 Bloch 구면의 위상과 개념적 간섭곡선으로 설명합니다. 특정 오류정정 코드의 완전한 구현이나 실험 데이터를 나타내지 않습니다. Figma 원본은 벡터와 텍스트를 편집할 수 있고 웹 SVG는 글자를 윤곽선으로 내보내 외부 폰트 의존성을 없앴습니다. 두 언어의 대체 텍스트와 캡션은 `src/data/research.json`에서 관리합니다. 출처·권리 구분과 재출력 절차는 [디자인 자산 안내](DESIGN-ASSETS.ko.md)를 참고하세요. 이 설명은 렌더링 검수 완료를 뜻하지 않으며 실제 검수 결과는 별도 기록합니다.

## 7. 구현과 공개까지의 단계

현재 결과물은 Astro 기반 정적 사이트와 분리된 콘텐츠 데이터, 검토·공개 모드, GitHub Pages 배포 안내를 갖춘 배포 준비본입니다. 로컬 기본 모드는 `review`이며 GitHub 배포 기본은 `public`입니다. 검사 방법과 환경변수는 [배포 안내](DEPLOYMENT.ko.md)에 정리했습니다. 실제 검사 결과는 최종 검수 기록과 함께 확인하며, 배포 성공을 의미하지 않습니다.

1. 교수·운영자가 현재 구성원, 최신 논문, 연구 소개, 모집 여부, 공개 권한을 확인합니다.
2. 공개 저장소 [qit-postech/qit-postech.github.io](https://github.com/qit-postech/qit-postech.github.io)를 사용합니다. 교수·운영자 계정의 역할 부여는 별도로 확인합니다.
3. 업로드할 파일을 선별합니다. 공개 저장소에는 사이트 코드·승인된 데이터·필요 문서만 넣고 원본 조사 HTML/JSON, 전체 원문 아카이브, 개인 연락처, PPT, 비공개 연구자료는 포함하지 않습니다. Git 이력에 이미 들어간 자료도 별도 확인합니다.
4. 루트와 저장소 하위 경로에서 두 언어 페이지, 직접 URL 접근, 내부 링크, 검색, 이미지, 모바일·키보드 사용을 확인합니다. 검토 모드의 `noindex`는 접근 통제가 아닙니다.
5. POSTECH SITES 운영 절차와 외부 호스팅 가능 여부를 담당자에게 확인하고 필요한 신청·승인을 진행합니다.
6. `main` 푸시 또는 수동 실행으로 GitHub Pages를 게시한 뒤 실제 주소에서 검수합니다. 기관 도메인을 연결한다면 기존 서비스의 영향과 복구 방법을 합의하고 DNS·HTTPS까지 확인합니다.
